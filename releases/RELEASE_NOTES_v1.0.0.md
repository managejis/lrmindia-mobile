# ABBA Sunday School v1.0.0

First public release of the ABBA Sunday School Android app.

## Download
- **ABBA Sunday School.apk** (Android, ~58 MB)
- SHA-1: `7af2c0a3f6e66fc60064ba7bd4761d0e7ecdd24a`

## Install
1. Download the APK on your Android phone.
2. Open it and allow "Install from unknown sources" if prompted.
3. Tap Install.

## What's included
- Sunday School lessons with lesson guides
- Student workbook download from the landing page
- Tips in all supported languages
- Right-to-left support for Urdu; Odia and Urdu notes
- Language ordering and copyright text updates
- Fixes: lesson guide table overflow, Next button style
